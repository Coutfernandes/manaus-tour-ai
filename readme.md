# 🎭 Manaus Tour — Agente Corporativo IA

> Projeto desenvolvido para o Challenge ONE (Alura)

## 🎯 Objetivo
Agente de Inteligência Artificial capaz de responder dúvidas de colaboradores e turistas sobre os **Pontos Turísticos de Manaus**, utilizando arquitetura RAG (Retrieval-Augmented Generation) com base em documentos oficiais.

## 🛠️ Tecnologias Planejadas
- **Linguagem:** Python
- **Backend:** FastAPI
- **Orquestração de IA:** LangChain
- **Modelo de LLM:** Google Gemini API (Free Tier)
- **Deploy:** Vercel
